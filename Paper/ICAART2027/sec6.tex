\section{\uppercase{Conclusion}} \label{sec6}
In this study, we proposed a method that adaptively selects RAG configurations based on query characteristics to balance accuracy and computational cost. Specifically, we trained ranking models (RMs) to rank candidate RAG configurations using query features, document features, and configuration parameters. We selected the final configuration using a multi-objective score that aggregates precision, recall, $F_1$ score, and execution latency according to user-defined priority weights.
%By adjusting these weights, users can flexibly switch between accuracy-oriented and cost-oriented operational policies.
In this 80-question evaluation, the balanced policy achieved BERTScore $F_1$ and execution time close to the empirically identified Most Frequent Setting. Other policies showed different quality-cost trade-offs, and the proposed policies outperformed the Adaptive-RAG implementation evaluated here; paired Wilcoxon tests were limited to comparisons with that implementation. Because ranker selection used ranking results on the same evaluation set, these findings are exploratory and do not constitute an independent final test. The top-$K$ results are oracle-assisted shortlist evaluations that use reference answers and execute every candidate; they do not demonstrate reference-free user selection. Adding query and document features provided a modest NDCG@1 increase over configuration features alone.
% Ablation analysis confirmed that while RAG configuration information forms the foundational baseline for ranking, comprehensively integrating query and document features achieves the highest ranking accuracy (NDCG@1=68.52\%, Hit@5=65.00\%). 
Feature-importance analysis showed that generator models and retrieval strategies strongly influence overall performance, while input features such as cosine similarity and document length contribute to fine-grained ranking decisions.

Future work includes evaluating the method with an independent test set and verifying whether query- and document-aware selection improves final QA performance over a configuration-only ranker and strong fixed configurations. We will also measure the costs of obtaining and preparing the document input and extracting its features, test reference-free selection, improve RM ranking accuracy, and develop an automated method for estimating priority weights, such as gating networks that infer suitable weights from query difficulty and runtime system constraints.
